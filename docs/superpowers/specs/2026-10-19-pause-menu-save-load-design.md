# 2026-10-19 暂停菜单与完整对局存档设计

## 目标

- `Esc` 打开/关闭游戏内暂停菜单：继续游戏、保存进度、读取进度、重新开始、退出游戏。
- 保存单个手动存档槽，读取后继续同一局 RTS 对局。
- 主菜单提供“继续游戏”，使退出程序后仍能读取存档。
- 不改变现有战斗、寻路、建造、采集与胜负规则；存档层只负责捕获和恢复长期状态。

## 非目标

- 不序列化逐帧路径、飞行中的箭、临时攻击目标、动画播放位置、粒子与 UI 选择状态。
- 不做多存档槽、云存档、自动存档。
- 不允许在对局已结束后保存；结算界面继续使用现有“再来一局”。

## 总体方案

### 预制体身份与目录

- 新增 `SaveIdentity`：挂在所有可存档预制体根上，保存稳定的预制体 GUID。
- 编辑器工具扫描 `Assets/Prefabs` 中的建筑、单位、可清除灌木，补上 `SaveIdentity`，并生成
  `Assets/Resources/SavePrefabCatalog.asset`（GUID -> 预制体引用）。
- 运行时只通过目录查找预制体，不使用对象名称或场景层级，因此 AI 的 `*_AI` 命名、生产单位重名、
  后续改名都不会破坏存档。
- 任意一个待保存单位/建筑缺少身份组件时，保存直接失败并报告原因，不产生静默丢失的存档。

### 存档文件

单槽 JSON：

`Application.persistentDataPath/AtTheGates/save_slot_1.json`

使用 `version` 字段校验兼容性。写入时先写临时文件再替换正式文件，避免中途失败留下半个 JSON。
读取前完整解析与校验；损坏、版本不兼容或目录缺项时返回失败，不重载场景。

快照包含：

- 玩家资源；玩家阵营；`GameState` 的胜负状态与“曾经拥有指挥部”记录。
- AI 阵营资源、当前建造序号、波次和各类计时器。
- 所有单位：预制体、位置、朝向、队伍、当前/最大生命、工人携带量与手动空闲状态。
- 所有建筑/树木/矿：预制体、位置、队伍、当前/最大生命、阻挡状态、建造剩余时间、
  生产队列与当前生产进度、是否已成废墟。
- 所有资源点：剩余量、最大值、重生计时。
- 所有未清除的灌木。
- 驻塔关系：塔内弓箭手的预制体、生命和队伍。
- 摄像机位置与缩放。

### 读取流程

1. 解析并校验存档；失败则停留当前界面并显示原因。
2. 设置待加载标记，恢复 `Time.timeScale = 1`，重载 `SampleScene`。
3. 场景启动后，`SaveGameRuntime` 发现待加载标记，进入恢复协程：
   - 销毁当前场景的全部单位、建筑/景物、灌木。
   - 从目录实例化存档中的建筑、单位、灌木。
   - 等待一帧，让现有 `Awake/OnEnable/Start` 建好血条、注册占地和初始化组件。
   - 应用生命、建造进度、生产队列、资源点、废墟、工人携带物等状态。
   - 用同一预制体重建驻塔弓箭手并调用现有 `TowerGarrison.Garrison`。
   - 恢复经济、AI、胜负记录和摄像机，最后恢复时间流动。
4. 不恢复临时路径和攻击目标；移动单位读取后停住，工人按原有自动上岗规则重新找活，AI 重新下达指令。

## 组件设计

- `SaveIdentity`：只保存 `prefabId`，无运行时逻辑。
- `SavePrefabCatalog`：`ScriptableObject`，GUID 到预制体。
- `SaveGameService`：静态服务，负责路径、读写、校验、待加载标记、快照捕获/应用。
- `SaveGameRuntime`：放在对局场景的管理对象上，处理场景启动后的异步恢复。
- `PauseMenu`：ESC 开关、按钮、暂停时间、状态提示；放置模式下 ESC 仍先取消放置。
- 现有玩法类只增加最小的 `CaptureState` / `RestoreState` 接口，不改变正常 Update 行为。

## UI

- 暂停菜单使用现有 `Carved_9Slides` 面板与蓝色九宫格按钮，保持与 HUD/主菜单一致。
- 全屏半透明遮罩，中央竖排五个按钮；底部显示“上次保存时间/操作结果”。
- 主菜单新增“继续游戏”按钮：无有效存档时禁用；有存档时直接加载 `SampleScene` 并恢复。
- 读取失败和保存失败都用面板内文字提示，不弹系统对话框。

## 边界与安全

- 对局结束后 ESC 不打开暂停菜单，避免覆盖结算界面。
- 放置建筑时 ESC 只取消放置，不打开菜单。
- 暂停时 `Time.timeScale = 0`；继续、读取、重新开始前恢复为 1。
- 保存、读取、重新开始、退出均使用显式按钮；退出不会自动保存。
- 读取时若存档引用的预制体已不存在，整次读取失败，不会生成残缺对局。

## 测试

- PlayMode 存档回环：经济、单位生命/位置、工人携带物、驻塔弓箭手、在建建筑、
  生产队列、资源点剩余量、废墟阻挡、摄像机，保存后清场再恢复并逐项断言。
- 损坏存档/版本不兼容：返回失败、不抛异常、不改变当前对局。
- 暂停菜单：ESC 切换时间缩放与面板；放置模式下 ESC 不打开菜单；读取/重开前时间恢复。
- 主菜单：无存档时“继续游戏”禁用，有存档时可用。
- 现有 47 项 PlayMode 回归全部保持通过。
