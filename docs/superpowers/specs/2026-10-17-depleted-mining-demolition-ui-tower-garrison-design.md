# 采空停工、UI 拆除与塔楼驻防设计

日期：2026-10-17  
状态：用户已确认施工方案

## 一、采空立即停工

- Gatherer.StepHarvest 开头同时检查 node == null 或 node.Depleted。
- 采空或矿对象销毁时立即结束采集行程，不再播放后续挖矿动作。
- 保留 60 秒重生和重生后自动复工。

## 二、拆除入口改为 UI

- SelectionPanel 增加“拆除”按钮，仅在选中的己方非主基地建筑可拆时显示。
- 主基地和中立资源不可拆时隐藏。
- 点击后执行现有队列退款、50% 建筑退款、选中清理和占地释放；Delete 保留为可选快捷键。
- SelectionPanel 高度增加 40，MinimapPanel 同步下移 40，避免遮挡。

## 三、塔楼单弓箭手驻防

- 新增 TowerGarrison，每塔最多一名弓箭手。
- 选中一名 Archer 后右键己方塔楼入塔；第二名弓箭手及其他兵种不得进入。
- 入塔后原弓箭手从战场移除，不重复计入 UnitActor.All；塔使用弓箭手的 attackDamage、attackRange、attackCooldown、projectile 和 projectileSpeed 自动攻击。
- 再右键塔楼可让弓箭手退出到附近合法格。
- 拆塔或塔被摧毁时，弓箭手也会退出，不消失、不复制。
- 无驻防弓箭手时塔不攻击。

## 四、验证

- 采空后立即停止动作，无额外挖矿周期；重生后恢复。
- UI 拆除按钮的显示条件、退款和原地重建正确。
- 每塔最多一名弓箭手，其他兵种和第二名均被拒绝；退出不复制、塔毁不丢兵。
- 回归主基地完工解锁、民房产工人、金矿重生、清草、驻守、小地图和事项 1 的障碍格恢复。
- 完成后退出 Play Mode，恢复干净场景并删除探针。
